# Homepage wireframe (Editorial × Desk)

Scope: grooming-dogs.com homepage, desktop and mobile wireframes; prototype follows. Visitor mode: read.
Audience: owners with one concrete grooming question, often on a phone. Task: find the answer, see the trade-off, know when a groomer or vet takes over.
Constraints: only the 22 published pages and their anchors; live identity kept (espresso, copper, honey; Literata, Source Sans 3) plus three accents; restructuring allowed.

## Direction contract

FORM: "Ask first" (seed:a63a3209d9aad84c, degraded roll, no challengers; user locked it 2026-10-17).
THESIS: The homepage opens on the reader's question, not a brochure. Search is the hero; everything below is a reference shelf of four colour-coded chapters. Refuses hero → card rows → carousel.
OWN-WORLD: Espresso masthead and copper actions from the live site; honey only as highlight. Each chapter owns a quiet ground and an accent: coat = sage, plate = honey-warm, problems = mist-slate, groomers = heather. A field-guide thumb index in those colours is the one signature move. Literata headings, Source Sans 3 text, line icons, credited photos, V1 tool drawings in espresso.
STORY: Ask → answer in place → browse by dog → coat → tools → problems → groomer → how the guide works.
FIRST VIEWPORT: H1, one large question field, four real questions, browse-by-dog row with three real photos, hero photo with credit; thumb index visible at the right edge.
SIGNATURE INTERACTION: Typing prints results under the field; choosing one opens the reading slip. The coat chosen in chapter 1 lights the plate in chapter 2.
RISK: Search-first can feel empty to browsers; the browse-by-dog row and the thumb index carry them.
